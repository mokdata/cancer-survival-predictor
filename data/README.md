# Data layout

Patient-level TCGA files are deliberately stored inside this project so the
analysis remains self-contained locally, but they are excluded from Git.

| Path | Purpose | Versioned |
| --- | --- | --- |
| data/raw/tcga-brca/ | Original cBioPortal download | No |
| data/processed/ | Cohort generated by the preprocessing module | No |
| data/brca_clinical.csv | Legacy synthetic demonstration dataset | Yes |
| data/figures/ | Current published demonstration figures | Yes |

Expected local raw file:

~~~text
data/raw/tcga-brca/brca_tcga_pub2015_clinical_data.tsv
~~~

Build the cleaned cohort from the repository root:

~~~bash
python -m src.tcga_preprocessing
~~~

The command also writes an aggregate, reviewable report to
reports/tcga_cohort_summary.md. The processed CSV contains patient identifiers
for traceability and must remain local.
